## Hardware

Schematics, PCB layout, BOM and 3D/mechanical files for RaraPLC, built around the STM32H743.

Status: seed stage. The design is being finalized and reviewed in a private repository and will be published here once it reaches a stable, fabrication-ready state (schematics, PCB, BOM with LCSC part numbers, and 3D files).
