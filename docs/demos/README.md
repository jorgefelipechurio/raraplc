# Interactive UI demos

Self-contained HTML mockups of the RaraPLC software surfaces. Open any file in a browser; the buttons work (Confirm / Edit / Discard reveal the next step). They are concept designs: no backend, and all names and data are fictional.

| Demo | What it shows |
|---|---|
| [`bridge.html`](bridge.html) | RARA Bridge: live diagnosis over USB, raw CLI next to Claude's reasoning. See [`../SUPPORT_BRIDGE.md`](../SUPPORT_BRIDGE.md) |
| [`ears.html`](ears.html) | Extended EARS Runtime: new machine project, then intent → EARS → HAZOP → compiled block. See [`../AI_WORKFLOW.md`](../AI_WORKFLOW.md) |
| [`chat.html`](chat.html) | The technician's chat on a phone: EARS cards, HAZOP finding, hand-off to Bridge, voice note, setpoint change |
| [`acervus.html`](acervus.html) | Acervus home: one Libris per machine and the support boards. See [`../ACERVUS.md`](../ACERVUS.md) |

With GitHub Pages enabled on this repository, they can be opened directly from the browser at `https://jorgefelipechurio.github.io/raraplc/docs/demos/<file>.html`.
