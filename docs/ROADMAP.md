## Roadmap

This is a working roadmap, not a fixed schedule. It will be revised as the project and the community around it grow.

### Near term

Publish the v0.1 hardware design: schematics, PCB layout, BOM with LCSC part numbers, minimizing component footprint where possible.

Ship a firmware skeleton: STM32H743 HAL/Cube bring-up, RTOS choice, and a first IEC 61131-3-inspired logic runtime.

Document a first revamping case study end to end: migrating one legacy, closed-source PLC installation to RaraPLC, with Claude assisting the integration engineer throughout.

### Mid term

Integrate with the STM32Cube / Arduino_Core_STM32 ecosystem and evaluate the ST Partner Program and ST for Startups as formal channels into the STMicroelectronics ecosystem.

Build a ROS 2 bridge for robotics and automation integration.

Set up a university/education outreach track (technical universities, coursework and reference designs).

### Long term

Grow a self-sustaining open source community around RaraPLC: contributors, documented installed-machine case studies, and a public library of revamping patterns.
